# Practice — тренажёр английских слов

Локальное приложение для заучивания английских слов с **интервальными
повторениями** (алгоритм SM-2, как в Anki). Перевод можно вводить самому
или запрашивать у ИИ через **Groq API**.

## Возможности

- **Словарь** — добавление слов, свой перевод или кнопка «Перевод от ИИ»,
  поиск, редактирование, удаление.
- **Повторение** — карточки со словами, которые пора повторить; оценка
  ответа по 4 кнопкам (`Не помню / Трудно / Хорошо / Легко`), после чего
  SM-2 планирует следующий показ. Управление с клавиатуры: `Пробел` —
  показать перевод, `1–4` — оценка.
- **Обзор** — сколько слов всего, сколько к повторению, выучено, повторено
  сегодня.

## Стек

- Next.js 16 (App Router) + TypeScript + Tailwind CSS 4
- SQLite через `better-sqlite3` — файл `data/practice.db` (не коммитится)
- Groq API (OpenAI-совместимый) — перевод, вызывается только на сервере

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

Впишите `GROQ_API_KEY` в `.env.local` (ключ: https://console.groq.com/keys),
откройте http://localhost:3000. Без ключа работает всё, кроме кнопок перевода ИИ.

## Как работает планирование (SM-2)

У каждого слова: число успешных повторений подряд, фактор лёгкости
(`easeFactor`, старт 2.5), текущий интервал в днях и дата следующего показа.

- оценка `< 3` (ошибка) → повторения обнуляются, слово вернётся через 10 минут;
- оценка `≥ 3` → интервал растёт: 1 день → 6 дней → `интервал × easeFactor`;
- `easeFactor` корректируется по оценке, минимум 1.3;
- слово считается «выученным», когда интервал дорос до 21 дня.

Новое слово сразу попадает в очередь повторения (`dueAt = сейчас`).
